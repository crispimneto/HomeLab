# rclone Home Lab

Páginas públicas do aplicativo **rclone Home Lab**, exigidas pelo Google para publicar o app OAuth usado pelo [rclone](https://rclone.org) no backup de um servidor doméstico (Raspberry Pi) para o Google Drive.

- `index.html`: página inicial do app
- `privacidade.html`: política de privacidade

É um aplicativo de uso pessoal: o rclone original, sem modificações, acessando apenas o Google Drive do próprio dono.

Publicado com GitHub Pages.
